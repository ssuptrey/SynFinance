## 🆘 Troubleshooting

### Common Issues & Solutions

#### **Issue: "ModuleNotFoundError: No module named 'src'"**

```bash
# Solution 1: Make sure you're in project root
cd E:\SynFinance

# Solution 2: Set PYTHONPATH
set PYTHONPATH=E:\SynFinance
python examples/run_demo.py
```

#### **Issue: "Database connection failed"**

```bash
# Solution: Demos auto-fallback to SQLite (no setup needed)
# SQLite is used automatically if PostgreSQL unavailable

# To verify:
python examples/api_examples/api_demo.py
# Should show: "Using SQLite database"
```

#### **Issue: "Permission denied: output/"**

```bash
# Solution: Create output directory
mkdir examples\output
mkdir examples\output\charts
mkdir examples\output\reports
```

#### **Issue: "Demo runs but shows no output"**

```bash
# Solution 1: Check output directory
dir examples\output

# Solution 2: Run with verbose flag
python examples/fraud_detection/demo_fraud_detection.py --verbose

# Solution 3: Check for errors
python examples/run_demo.py --debug
```

#### **Issue: "ImportError: cannot import name 'AdvancedFraudDetector'"**

```bash
# Solution: Reinstall in development mode
pip install -e .

# Or set PYTHONPATH
set PYTHONPATH=E:\SynFinance\src
```
